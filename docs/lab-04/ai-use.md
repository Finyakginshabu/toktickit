## Reflection

In Lab 4, the same contract-first workflow from Lab 3 was applied at larger scale -> spanning Actions Taken CRUD, a multi-condition Resolution Gate, three role-specific dashboards, optimistic concurrency, Zen Green design system tokens, WCAG AA accessibility, and full Playwright E2E coverage. The strict plan-first discipline continued to pay off: every issue had an explicit implementation plan reviewed against the acceptance criteria before a single file was touched, which kept multi-file migrations (ActionTaken schema, dashboard aggregations, trigger-based delete protection) coherent and conflict-free across the full stack.

Using Gemini 3.8 High again proved necessary for Lab 4's complexity — the cascading nature of the Resolution Gate required the model to hold a large amount of context simultaneously without losing traceability to the original contracts.
